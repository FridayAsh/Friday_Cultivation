# Friday Cultivation（Friday修仙）

> Minecraft 1.20.1 / Forge 47.x 修仙模组 —— 复刻「小翔的修仙世界」完整修仙体系。

## 简介

一款以修仙为主题的 Minecraft Forge 模组，完整复刻了「小翔的修仙世界」的核心玩法：从凡人（锻体）起步，历经练气、筑基、金丹、元婴、化神、炼虚、合道、大乘、渡劫，经散仙旁支或真仙主线，一路修至玄仙、仙君、仙尊、仙王、半圣、圣人、半帝，最终登临大帝的完整修行路径。包含灵根、体质、身份、法术、功法、炼丹、炼器、阵法、宗门、地府轮回、渡劫雷劫、帝法帝兵等机制。

- **Mod ID**: `friday_cultivation`
- **版本**: 0.1.0
- **环境**: Minecraft 1.20.1 / Forge 47.2.0 / JDK 17

**突破主链路**：凡人 → 锻体 → 练气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合道 → 大乘 → 渡劫 → 散仙（旁支）→ 真仙 → 玄仙 → 仙君 → 仙尊 → 仙王 → 半圣 → 圣人 → 半帝 → 大帝

**突破机制**：
- 锻体十层圆满 → 突破进入练气一层
- 练气九层圆满 → 选择筑基之道（地/天/人）并渡雷劫 → 筑基
- 筑基大圆满 → 选择金丹之道并渡雷劫 → 金丹
- 金丹九转圆满 → 渡雷劫 → 元婴；合道界境圆满 → 渡雷劫 → 大乘
- 真仙/玄仙每 3 重天渡劫一次（三重天 3波×9道、六重天 6波×9道、九重天 9波×9道）
- 仙君每重天 3 波、仙尊 4 波、仙王 5 波（九重天圆满 9 波 → 半圣）
- 半圣/半帝突破渡劫 9 波×9 道；大帝每帝界突破渡劫（9 波起每界 +1）
- **半帝 → 大帝前置**：需击杀过大帝生灵 + 自创并装备帝法功法
- **半圣/圣人/半帝/大帝**：需修为值满 + 悟道值满（悟道条）方可突破
- 渡劫失败境界倒退（渡劫期巅峰失败另走散仙机制）；突破小境界奖励真元，大境界奖励更多并全属性成长
- 玩家基础生命值按境界标准生命值（×4 全局倍率），锻体加成固定继承（150 × 锻体百分比）

## 核心系统

### 修炼（Cultivation）
- 装备功法后自动吸收周围灵气，修为满后可突破
- 灵气粒子、蒲团打坐、聚灵阵、灵石补充灵气
- 修炼加速度、时间加速（最高 ×10000）

### 灵根（Spirit Root）— 25 种
五行单灵根、双灵根（10 种组合）、变异灵根等，影响灵气吸收效率、可学法术与突破奖励。

### 体质（Physique）— 13 种
先天剑体、无垢仙体、混沌体、绝脉石体等，提供特殊属性加成与玩法规则（如混沌体突破奖励随机法术）。

### 法术（Spell）— 58 种
主动/被动法术：御剑飞行、灵气飞行、剑气、飞剑、神通、时停、锁灵、佛怒火莲、无上生死平衡等，按境界解锁。

### 功法（Technique）— 约 27 种
木系长寿、火系焚身、金系剑诀、无垢仙诀等，装备后提供属性加成与特殊能力。

### 身份（Identity）— 23 种初始身份
决定初始属性、灵根/体质倾向、寿命与地府轮回表现。

### 炼丹（Alchemy）与炼器（Refining）
筑基丹、金丹丹、血气丹、回灵丹、造生丹等丹药；玄铁剑、青木剑等法宝；五级品质（低/中/高/极品/仙品）。

### 阵法（Formation）— 7 类
聚灵阵、宗门护盾、时停域、长生阵、禁飞阵、迷宫阵、丰收阵；五级阵盘（低/中/高/极品/仙品）。

### 宗门（Sect）
宗门令牌、宗门护盾、宗门建筑、宗门角色体系。

### 地府与轮回（Difu & Reincarnation）
- 死亡后进入地府（灵魂状态），可选择转世重生（重开人生）或原身回归
- 命书转世、轮回命盘等物品
- 索命使追魂机制

### 渡劫（Tribulation）
金丹起各境界按子阶段渡雷劫，波数与强度随境界递增；真仙/玄仙每 3 重天渡劫（3/6/9 波×9 道）、仙君 3 波/仙尊 4 波/仙王 5 波逐境递增、半圣/半帝/大帝各 9 波×9 道；渡劫失败境界倒退甚至身死道消（散仙之路）。大帝前置：需击杀过大帝生灵并自创帝法功法方可从半帝突破至大帝。

### 真元（Zhenyuan）
突破获得可自由分配真元，强化体质/筋骨/身法/法伤/气海五属性，并提供生命、移速、法伤等加成。

### 妖兽（Beast）
独立妖兽境界体系（凡兽→妖圣），妖兽可修炼成长。

## 客户端界面

- 修仙主面板（属性、灵根、体质、法术、功法、宗门、突破）
- HUD：境界、修为、灵气条实时显示
- 游历修士交互界面（对话、交易、背包）

## 开发与构建

### 环境要求
- JDK 17
- Minecraft 1.20.1 / Forge 1.20.1-47.2.0

### 构建
```bash
gradlew build
```
产物位于 `build/libs/`，同时同步到 `jars/` 目录供直接部署。

### 部署
将 `jars/Friday_Cultivation-0.1.0.jar` 复制到游戏 `mods` 目录即可。

### 目录结构
```
src/main/java/com/friday/cultivation/
├── cultivation/        # 核心数据：境界、灵根、体质、修炼、真元、法术、功法
│   ├── realm/          # 境界与子阶段枚举
│   └── qi/             # 灵气系统
├── entity/npc/         # 游历修士、索命使 NPC
├── event/              # 事件处理：渡劫、威压、转世、功法效果、灵气吸收
├── network/            # 网络包：突破请求、面板交互、转世选择、飞行输入等
├── item/ block/ inventory/  # 物品、方块、容器
├── worldgen/           # 地府村庄等世界生成
└── client/             # 客户端渲染、HUD、界面
src/main/resources/
├── assets/friday_cultivation/
│   ├── lang/           # 中/英本地化
│   └── patchouli_books/ # 修仙全书（Patchouli 文档）
└── data/               # 数据包（配方、战利品等）
```
