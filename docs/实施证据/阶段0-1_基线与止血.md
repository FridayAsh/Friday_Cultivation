## 3. 阶段 1 改动

### 3.1 飞行事件单一注册

删除 `FridayCultivationMod` 对 `CultivationFlightEvents.class` 的手动注册，保留 `CultivationFlightEvents` 自身的 `@Mod.EventBusSubscriber` 注册方式。这样飞行 tick 不会因为两套注册路径而每 tick 执行两次。

### 3.2 开发网络包服务端授权

新增 `network/ServerAuthorization` Module：

- `RealmSelectionPacket`：服务端要求 OP 或玩家背包中存在境界选择令牌；
- `EditPlayerStatsPacket`：服务端要求权限等级 2（OP）；
- 拒绝时只发送服务端生成的提示，客户端不能通过修改界面或 Packet 字段绕过；
- 两个 Packet 均在读取和修改 `CultivationData` 前经过授权 Seam。

### 3.3 御剑登录/重启止血

- 登录时删除原先直接 `clearSwordFlight()` 的逻辑；
- `CultivationFlightHandler.restoreAfterLogin` 从 Capability 恢复当前服务器进程的运行缓存；
- `stopSwordFlight` 在静态缓存缺失时回读 Capability 中的 ItemStack 和原槽位，避免退出重进后归还路径丢剑；
- 静态 Map 仍不是最终的 FlightState 方案，阶段 7 将把它降为可丢弃运行缓存并收敛全部生命周期。
